Machine Learning Architecture & Pluggable Adapter

The RetinaAI backend is built with a decoupled adapter pattern. Your ML teammate can train models in MATLAB or PyTorch, export them, and place them in models/exported/dr_model.onnx. The system automatically switches to their neural network with zero frontend or backend edits!

QNet Quantized

Ultra-lightweight INT8 edge model designed for instant on-device binary triage (Referable vs Non-referable) at low-power rural PHCs without GPU.

LNet Localization

Sub-pixel lesion segmentation network targeting IDRiD annotations for microaneurysms, hemorrhages, and hard exudates.

GNet 5-Class ICDR

Full 5-class clinical grading network (Grades 0 to 4) with Grad-CAM gradient backpropagation for visual explainability.
